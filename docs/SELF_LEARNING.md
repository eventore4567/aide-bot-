# Apprentissage autonome

Aide Bot propose des contenus gratuits directement dans Discord afin qu’un débutant puisse progresser sans ouvrir un ticket pour chaque question.

## Commandes

- `/apprendre parcours` — liste les mini-parcours disponibles ;
- `/apprendre lecon sujet:<clé> numero:<n>` — affiche une leçon, une explication et un exercice pratique ;
- `/apprendre quiz sujet:<clé>` — pose une question interactive avec correction ;
- `/apprendre glossaire terme:<mot>` — explique rapidement un terme Discord.

## Mini-parcours

Les parcours actuels couvrent :

- bases de Discord ;
- construction d’un serveur compact ;
- permissions et sécurité ;
- création d’un premier bot Discord.

Chaque leçon contient un exercice. L’objectif est d’apprendre en faisant plutôt que de seulement lire un long tutoriel.

## Positionnement par rapport aux formations

L’apprentissage autonome est gratuit et accessible immédiatement. Une formation classique reste un parcours accompagné, débloqué par une invitation valide. Les offres VIP et extensions restent personnalisées et soumises à validation du paiement par la Direction.

Le chemin recommandé est :

`/chercher` → `/apprendre` → challenge pratique → entraide si nécessaire → formation accompagnée si le membre veut aller plus loin.

Les mini-quiz ne donnent pas automatiquement de réputation afin d’éviter le farm répétitif. Les récompenses restent liées aux actions réellement validées : challenges, aides et formations.
