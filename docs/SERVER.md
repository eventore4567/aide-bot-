# Structure du serveur

Objectif : **15 salons permanents maximum**. Les tickets sont temporaires/dynamiques et ne comptent pas dans cette limite.

## INFORMATIONS
- `👋・bienvenue`
- `📜・règlement`
- `📢・annonces`

## APPRENDRE
- `🎓・formations`
- `📚・ressources`
- `🧩・presets`

## COMMUNAUTÉ
- `💬・général`
- `🆘・entraide`
- `⭐・avis`

## SERVICES
- `🎫・commencer`
- `🧑‍🏫・recrutement`
- `💎・vip`

## STAFF
- `📋・staff`
- `🧾・logs`
- `🧠・suivi-formations`

## Rôles

`👑・Direction` > `📘・Responsable Formation` > `🎓・Formateur` > `🤝・Helper` > rôles d’expertise > `✅・Apprenant certifié` > `💎・VIP` > `👤・Membre`.

Le rôle du bot doit être placé au-dessus de tous les rôles qu’il doit attribuer ou modifier.
